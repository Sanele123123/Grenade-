Logo & Image Generation

          
Connect your Recraft API key to generate real logos and photos for clients who ask us to create their visuals — logo options for "Please make me a logo", and website photos for "Please make me all". One key covers both; Recraft handles logos as scalable vector art and photos as realistic raster images.

        

        

          
API Configuration

          

            
API Key

            

              

                
                Show
              

              
Get your key from recraft.ai — log in, then open your profile.

            

          

          

            
Connection

            

              
              

            

          

        

        

          
How it's used

          

            Logos: when a client selects "Please make me a logo" under Assets & Visuals and clicks Generate logo, the engine builds two prompts from their company name, business type, personality, theme, and colour palette, then calls Recraft's vector generation endpoint for two distinct logo options (an icon+text mark and a text-only wordmark).


            Images: when a client selects "Please make me all" under images/photos and clicks Generate images, the engine builds one prompt from the same business details and calls Recraft's raster generation endpoint for 4 realistic photos (storefront, product close-up, interior, team).


            This is entirely separate from Claude — Claude only builds the website itself.
          

        

      


      
      

        

          
Build Mode

          
Choose how the build pipeline is orchestrated. Both modes require the same core infrastructure — provisioning, plugin install, and an AI provider call. This controls how the steps are wired together.

        

        

          
Orchestration mode

          

            

              
Recommended

              
Direct Build

              
BBP handles the AI generation call and the Netlify deploy in a single integrated pipeline. More control, less external setup.

            

            

              
Alternative

              
Webhook + n8n

              
BBP fires webhooks; n8n orchestrates the steps visually. Easier to debug and modify without redeploying. n8n is free when self-hosted.
